# Borrador (sin terminar) — versión local en Python + SQLite

Primer enfoque del sistema de ventas e inventario de Kary Fashion, pensado para una sola
computadora en la tienda. **Está incompleto**: tiene el esquema SQL (`sql/`), la lógica de
negocio (`app/`, `app/routes/`) y los logos, pero faltan las plantillas HTML, `requirements.txt`
y las pruebas, por lo que todavía no se puede ejecutar.

El desarrollo continúa en la versión web: [`../kary-fashion-web`](../kary-fashion-web).
Este borrador se conserva como referencia (reglas de negocio: anticipo mínimo de 50% en
pedidos, costo promedio con transporte prorrateado, cierre de caja, NCF) y puede eliminarse.
